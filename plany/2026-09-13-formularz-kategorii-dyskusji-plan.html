Wzorcowa dyskusja na GitHubie

Przycisk na stronie publicznej otwiera natywny formularz kategorii „propozycje-zmian-regulaminu”. GitHub tworzy z niego nową, uporządkowaną dyskusję.

zatwierdzony kierunekTDDbez serwera i tokenów
Rezultat: zalogowana osoba klika „Otwórz nową dyskusję”, wypełnia pola Koordynator i Problem oraz opcjonalne listy i pola pomocnicze, a GitHub publikuje odpowiedzi jako treść nowej dyskusji.

Zakres

  1. Dodać test kontraktowy wymagający pliku .github/DISCUSSION_TEMPLATE/propozycje-zmian-regulaminu.yml.
  2. Test ma dopuścić na najwyższym poziomie wyłącznie klucze obsługiwane przez GitHub Discussions: title, labels i body. Klucze name i description mają być zabronione.
  3. Zdefiniować dwa pola wymagane: Koordynator dyskusji i Problem. Priorytet, Obszar, proponowane rozwiązanie, alternatywy, materiały i powiązane decyzje pozostają opcjonalne.
  4. Usunąć z trzech przycisków niedziałające parametry title i body. Każdy przycisk ma otwierać bezpośrednio właściwą kategorię.
  5. Uruchomić testy Python i build Jekyll. Następnie utworzyć PR, poczekać na CI, scalić i sprawdzić formularz na domyślnej gałęzi.

Kryteria akceptacji

  • Formularz jest powiązany z istniejącym slugiem kategorii propozycje-zmian-regulaminu.
  • GitHub pokazuje natywne pola tekstowe i listy wyboru zamiast pustego edytora.
  • Przyciski w nagłówku, rejestrze dyskusji i przewodniku prowadzą do tego samego formularza.
  • Nie dodajemy OAuth, backendu ani sekretów do GitHub Pages.
