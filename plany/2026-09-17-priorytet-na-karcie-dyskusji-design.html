Źródło i reguły

ElementUstalenie
Źródło prawdyPole Priorytet formularza GitHub Discussion: Niski, Średni, Wysoki lub Nie określono.
WyświetlenieWysoki, Średni i Niski tworzą pigułę. Brak pola, odpowiedź _No response_ oraz Nie określono nie tworzą piguły.
KolorWysoki — czerwony, Średni — bursztynowy, Niski — zielony. Kolor jest wsparciem dla tekstu, nie jedynym nośnikiem informacji.
AktualizacjaEdycja dyskusji uruchamia Release, który pobiera świeżą treść formularza, odtwarza snapshot i publikuje Pages.
ZakresNie zmieniamy kart zamkniętych dyskusji, decyzji ani znaczenia istniejących etykiet GitHub.

Zmiany i testy

  1. RED: test normalizacji oczekuje pola priorytetu; test widoku oczekuje piguły nad koordynatorem oraz jej braku dla wartości nieokreślonej.
  2. GREEN: normalizator przenosi już parsowane pole do danych strony, a szablon i CSS tworzą pigułę.
  3. Regresja: testy istniejącego parsera, kart, archiwum i budowy Pages nadal przechodzą.
  4. W tym samym wdrożeniu dyskusje #7 i #8 dostają w GitHub wartość Wysoki, aby dane źródłowe i widok były zgodne.
