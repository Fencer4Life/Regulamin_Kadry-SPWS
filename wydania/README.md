# Zatwierdzone wydania

Ten katalog jest przeznaczony wyłącznie na formalnie zatwierdzone, niezmienne wersje regulaminu.

Aktualny projekt roboczy znajduje się w katalogu `regulamin/`. Do chwili formalnego zatwierdzenia katalog wydań nie zawiera dokumentu regulaminu.

Każde przyszłe wydanie powinno otrzymać:

- nazwę wskazującą sezon i numer wersji;
- odpowiadający tag Git;
- datę oraz podstawę zatwierdzenia;
- sumę kontrolną SHA-256 podaną w informacji o wydaniu.
